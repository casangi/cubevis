Standard views¶

Status: available.

What it is¶

Each standard view sets up the plots for one common inspection task in a single step, using the axes, quantity and averaging that the task needs. Every setting can be changed afterwards. Each view has a short description that the window shows on request.

What it is for¶

These views are the usual first pass over a new observation. Each corresponds to a display that AIPS or CASA users already know:

How it behaves¶

  • How each view’s values are computed. Each view is an ordinary plot, so its values follow How it is calculated and How it is calculated. In particular:

    • the antenna matrix averages each baseline over the whole selection;

    • the all-baseline waterfall combines baselines by maximum (baseline_combine="max");

    • the spectrum and time series use scatter averaging.

  • A suggested order for commissioning:

    1. Survey with the antenna matrix, Z-Score, phase stability and amplitude views. In the antenna matrix, an antenna that is bad on every baseline is a whole row and column.

    2. Confirm on single baselines with the waterfalls, the spectrum and the time series, stepping through baselines.

    3. Flag on whichever view shows the problem best.

    The steps are described in A commissioning workflow in The visplot window.

  • A view normally switches to the layout that suits it. The layout can be pinned, so that views change only the plots and not their arrangement.

From Python¶

visplot(vis="obs.ms", preset="antmatrix")
visplot(vis="obs.ms", preset="spectrum", antenna="EA01&EA02")
visplot(vis="obs.ms", preset="vplot", pin_layout=True, layout="one")

Limits¶

  • Flag boxes are refused on the antenna matrix. Find the antenna there, then flag it on a Baseline × Time view.
