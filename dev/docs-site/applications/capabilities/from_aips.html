Coming from AIPS¶

This page goes through the AIPS tasks that visplot takes the place of for inspecting and editing visibility data: TVFLG, SPFLG, FTFLG and EDITR for editing, and VPLOT, UVPLT, POSSM and LISTR’s matrix listing for display. For each display mode, option and menu item it gives the visplot equivalent: the Python argument, the value, or the setting in the window.

visplot does not copy the AIPS menus or keyboard use. It is designed for a web window, so one AIPS menu item may correspond to a setting plus a mouse action.

Review status

This table was compiled on 2026-11-16 from AIPS Memo 127 (Interactive flagging in AIPS, 2025), the AIPS CookBook and the visplot source, and no row has been reviewed yet. When a tester confirms a row, the Reviewed column gets their initials and the date. Corrections are welcome, especially for rows marked Different.

Status means:

  • Same: works the same way.

  • Different: available, but works differently; the note says how.

  • Partial: some of it is available.

  • Not yet: not available.

  • N/A: does not apply to how visplot works.

TVFLG: flagging¶

The reaches widen a box the way TVFLG’s flagging switches do. The baseline, spectral-window, scan and field reaches apply to a raster box with the All selected filter; with other filters only the channel and correlation reaches apply (see How the filters decide).
