Coming from plotms¶

This page goes through CASA plotms’s parameters in the order the CASA documentation lists them, and gives the visplot equivalent of each: the Python argument, the value, or the setting in the window.

Review status

This table was compiled on 2026-11-16 from the CASA plotms documentation and the visplot source, and no row has been reviewed yet. When a tester confirms a row, the Reviewed column gets their initials and the date. Corrections are welcome, especially for rows marked Different.

Status means:

  • Same: works the same way.

  • Different: available, but works differently; the note says how.

  • Partial: some of it is available.

  • Not yet: not available.

  • N/A: does not apply to how visplot draws.

visplot’s arguments are those of the visplot(...) task call; see Starting visplot.
